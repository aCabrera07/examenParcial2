REPORTE PARA OVERLEAF

1. En Overleaf, selecciona New Project > Upload Project.
2. Sube el archivo ZIP completo.
3. Abre Menu > Settings > Compiler y selecciona XeLaTeX.
4. El archivo principal es main.tex.
5. Pulsa Recompile.

El documento solicita Arial. Si Arial no se encuentra disponible en el servidor,
main.tex utiliza automáticamente TeX Gyre Heros, una alternativa visualmente
compatible que permite compilar el proyecto sin errores.

La captura de configuración de Google Maps fue redactada para ocultar la clave de
API. El proyecto no incluye ninguna credencial.
